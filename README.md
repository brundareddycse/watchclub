# watchclub

A private Letterboxd-style movie and series logging app.

## Stack
- React
- Tailwind CSS v4
- FastAPI
- MongoDB
- JWT Authentication
- TMDB API
- Framer Motion

## Features
- Watchlist / Watching / Watched
- Friends system
- Recommendations
- Share cards
- Stats dashboard
- TMDB integration
- Cinematic glowing UI
